::B3-01::Para Fraden, un sensor es un dispositivo que… {
=Recibe un estímulo y responde con una señal eléctrica
~Convierte cualquier energía en movimiento
~Amplifica señales débiles para el conversor A/D
~Almacena la medida en memoria digital
####Sensor\: estímulo → señal eléctrica; transductor\: energía → energía; actuador\: lo opuesto (S8).
}

::B3-02::Muestreas a 500 Hz una vibración de 400 Hz. ¿Qué observas? {
=Un alias de baja frecuencia (100 Hz) imposible de deshacer con filtrado digital posterior
~La señal correcta, porque 500 es mayor que 400
~Ruido blanco sin estructura
~La señal atenuada a la mitad de amplitud
####Nyquist exige fs ≥ 2·f. El alias aparece en |fs − f| \= 100 Hz y ya no se corrige (S8).
}

::B3-03::Repetibilidad y exactitud\: ¿cuál es la afirmación correcta? {
=Un sesgo estable (buena repetibilidad, mala exactitud) puede calibrarse; una dispersión aleatoria, no
~Son sinónimos en las hojas de datos
~La exactitud siempre es mejor que la repetibilidad
~La repetibilidad solo se define para sensores digitales
####Por eso la repetibilidad es la especificación clave\: el sesgo se corrige por calibración (S8).
}

::B3-04::La histéresis de un sensor es… {

~El menor incremento de estímulo detectable
####La salida depende del camino (ida o vuelta), una de las 8 características estáticas (S8).
}

::B3-07::«Los acelerómetros miden la gravedad y el movimiento del cuerpo a la vez» (Corke). Una consecuencia práctica es que… {
