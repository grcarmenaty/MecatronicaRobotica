::B6-06::¿Cuándo conviene elegir procesado clásico frente a aprendizaje profundo? {

::B6-07::La creencia (belief) de un robot es… {
=Una distribución de probabilidad sobre su estado, condicionada a medidas y controles pasados
~Su mejor estimación puntual de posición
~El mapa que ha construido hasta el momento
~La covarianza del ruido del sensor
####El robot no conoce su estado\: mantiene y refina una distribución (S28).
}

::B6-08::En el ciclo del filtro de Bayes, la predicción y la corrección hacen, respectivamente… {
=Crecer la incertidumbre (modelo de movimiento) y reducirla (verosimilitud de la medida)
~Reducir la incertidumbre y aumentarla
~Ambas reducen la incertidumbre
~Ambas la dejan igual si el robot no se mueve
####El latido predicción-corrección es el esqueleto de Kalman, EKF y partículas (S28).
}

::B6-09::El filtro de Kalman mantiene la creencia gaussiana para siempre si… {
=El sistema es lineal, el ruido gaussiano y la creencia inicial gaussiana
~El robot se mueve despacio
~La covarianza inicial es pequeña
~Las medidas llegan a frecuencia constante
####Basta propagar media y covarianza; casi ningún robot real es lineal → EKF (S28).
}

::B6-10::El riesgo característico del EKF es que… {
=Con no linealidad fuerte o incertidumbre grande puede divergir sin avisar
~Su coste crece exponencialmente con el tiempo
~No admite más de tres estados
~Necesita conocer la pose inicial exacta
####La linealización es una aproximación; la gaussiana deja de describir la creencia (S28).
}

::B6-11::La localización global (pose inicial desconocida) se resuelve mejor con filtro de partículas que con EKF porque… {
=Las partículas representan creencias multimodales y una gaussiana no
~Las partículas son más precisas en el seguimiento fino
~El EKF no admite mapas de balizas
~El filtro de partículas no necesita modelo de movimiento
####«Estoy en uno de estos cuatro pasillos idénticos» no cabe en una gaussiana (S29/S30).
